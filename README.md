# CameraController
Simple Camera Controls made easy - BindToPart (with mouse follow) and SetFOV; Customization available through chainable ModuleSettings



## Available Here!
- **[This repository](src/init.luau) ~ [src/init.luau](src/init.luau)**
- **[Wally](<https://wally.run/package/coffilhg/cameracontroller>)**

    ```toml
    CameraController = "coffilhg/cameracontroller@1.0.0"
    ```
- **Rotriever**

    ```toml
    CameraController = "github.com/Coffilhg/Useful-Modules@CameraController/1.0.0"
    ```
